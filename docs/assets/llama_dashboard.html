常用参数与功能说明

每行一个参数组；带空格的值用引号包住。不填写程序路径，也不填写 shell 命令。常用设置会同步到这里，也可直接编辑当前编译版支持的其他参数。修改后请先检查，再点击加载。

加载将中断模型服务并清空当前 KV 缓存。只在无处理/排队任务时执行；请暂停客户端的新请求。旧模型完全退出后才加载新模型，10 分钟未就绪或进程退出时自动尝试恢复原配置。保留当前编译版，暂不切换新候选二进制。

8080、metrics 由管理器保持，以维持 Dashboard 和 Codex 连接。工具执行、在线下载、多模型路由及认证/TLS 等服务架构参数在此禁用；完整帮助中可查看。其他模型的工具调用和思考强度支持取决于其模板，不能仅凭加载成功判断。
